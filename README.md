# 围棋教室 · 系统性围棋教学网页游戏

一个**纯前端、开箱即用**的围棋教学网页游戏，从零基础开始系统性地教授围棋。
内置完整的围棋规则引擎、循序渐进的闯关式课程、目标自动判定与可对弈的 AI。

> 无需安装、无需联网、无需构建工具 —— 用浏览器打开 `index.html` 即可游玩。

## ✨ 特性

- **完整规则引擎**：气、提子、禁着点（自杀）、打劫（简单劫）、中国规则数子，全部实现并经过测试。
- **系统化课程**：四章共 15 关，由浅入深，每关都有讲解、目标、分步提示与成功反馈。
- **交互式闯关**：每一步落子都会实时判定是否达成本关目标，错误落子会给出原因。
- **教学辅助渲染**：高亮“气”、征子推荐落点、最后一手标记、落子预览、坐标。
- **内置 AI 对手**：遵循基本棋理（提子、逃子、打吃、靠拢行棋），可驱动征子应手与自由对局。
- **自由对弈 / 沙盘**：9 / 13 / 19 路任选，可与 AI 对战或双人对下，支持停一手、悔棋、实时数子。
- **进度保存**：闯关进度自动保存在浏览器本地（`localStorage`）。

## 🚀 运行

直接用浏览器打开 `index.html` 即可。

若浏览器对本地文件有限制，可在项目根目录启动一个静态服务器：

```bash
# 任选其一
python3 -m http.server 8000
npx serve .
```

然后访问 `http://localhost:8000`。

## 🧪 测试

围棋的死活/征子题目对坐标极其敏感，因此所有关卡的题目与标准解法都用引擎做了离线验证：

```bash
node tests/verify.js
```

该脚本会校验规则引擎（提子、禁着点、打劫、数子）以及每一关的标准解法确实能达成目标。

## 🏗️ 设计要点

- **引擎与界面解耦**：`engine.js` 不依赖 DOM，可在 Node 下直接测试，便于保证规则正确。
- **题目可验证**：征子、枷、死活等位置在加入课程前，均用引擎进行了搜索/模拟验证
  （例如征子的可吃序列、枷的唯一罩点、直三的要害），避免“教错棋”。
- **教学友好**：教学关卡中玩家恒执黑；多数题目对手不应手（`noOpponent`），
  让初学者从容练习；征子关由 `escapeOnly` AI 自动逃跑以演示完整过程。

## 📝 规则说明

- 采用**中国规则**风格的数子（子空皆地）进行形势判断，用于教学示范；
  终局以双方连续“停一手”触发，比较双方占点判定胜负（教学版未计入贴目）。
- 打劫实现的是**简单劫**（禁止立即回提同一处单子），足以覆盖入门到中级教学场景。
